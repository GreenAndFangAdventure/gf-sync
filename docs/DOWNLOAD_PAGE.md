## GF Sync：讓公會名冊自動更新

裝好之後，你每次在遊戲裡下線，角色的等級、專業等資料就會自動更新到公會網站。只需要做一次，三個步驟。

**開始之前**：遊戲裡要先裝好「綠皮冒險工具箱」插件。

### 1. 下載

[下載 GF Sync（Windows）](<下載連結>)　`GFSync-Setup-<版本>.exe`

### 2. 安裝

打開下載的檔案，看完隱私權政策後一路按「下一步」，最後按「完成」。不用改任何設定，也不需要系統管理員權限。

> 如果出現藍色的「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。這是因為 GF Sync 還沒有數位簽章（申請中），不是病毒。

### 3. 在 Discord 允許

安裝完成後，瀏覽器會自己打開公會網站，同時跳出 GF Sync 的小視窗顯示配對碼。用 Discord 登入，確認網頁上的配對碼和小視窗上的一樣，按「**允許這台電腦同步**」。找不到網頁的話，按小視窗上的「重新開啟配對頁」；網頁要你輸入配對碼時，按「複製配對碼」再貼上。

看到「**GF Sync 已連結**」的通知就完成了。之後什麼都不用做：GF Sync 會在開機時自動啟動，你下線時自動同步。

### 常見問題

**右下角那個盾牌圖示是什麼？**
就是 GF Sync。圖示右下角有小點時：黃點＝等待你在網站按「允許」，紅點＝有問題（按右鍵可以看原因），灰點＝已暫停。

**瀏覽器沒有自己打開？**
按 GF Sync 小視窗上的「重新開啟配對頁」。如果還是打不開，小視窗上會顯示網址，請自己貼到瀏覽器。

**配對碼過期了？**
配對碼 10 分鐘內有效。過期後，工作列的盾牌圖示會顯示「配對碼已過期，點這裡重新配對」，按右鍵點那一行就會重新開始。

**找不到工作列的圖示？**
GF Sync 常駐在螢幕右下角的工作列。如果沒看到盾牌圖示，按一下工作列右邊的「^」，它可能收在裡面。

**安裝完什麼都沒發生？**
從「開始」選單打開「綠皮同步（GF Sync）」（安裝時勾選了「在桌面建立捷徑」的話，也可以用桌面捷徑）。如果電腦剛開機還沒連上網路，GF Sync 會等網路好了再自動打開配對頁。

**找不到遊戲？**
GF Sync 會請你選擇遊戲資料夾，選 `World of Warcraft`（或裡面的 `_forever_`）就可以了。

**會上傳哪些資料？**
角色名稱（包含名冊上的完整名稱「名字 姓氏」）、伺服器、陣營、公會與階級、等級、職業、種族、專業與配方，以及公會名冊。裝了綠皮冒險工具箱 0.11.0 以上時，還有製作與訂單：是否接單中、工錢，以及訂單的狀態與數量（只有角色 ID 和數字，不含名字和任何文字）。0.12.0 以上還有冒險單與職工單（地城、時間、人數、申請與錄取），其中冒險單的**短備註（最多 40 字）會上傳**，這是唯一會上傳的文字，只給公會成員看，請不要在備註裡寫個人資料。你自己的角色會附上存檔那一刻（通常是下線時）所在的區域名稱，不含座標；**不會上傳名冊上其他人在哪裡，也不會上傳任何人是否在線。** GF Sync 只讀取插件的存檔，不會修改任何遊戲檔案。詳見[隱私權政策](https://github.com/GreenAndFangAdventure/gf-sync/blob/main/PRIVACY.md)。

**怎麼更新 GF Sync？**
0.2.0 起，GF Sync 每天會檢查一次新版本，有新版時工作列選單和 Windows 通知會提醒你，點一下就會開下載頁；它只會通知，不會自己下載或安裝。也可以在盾牌圖示上按右鍵選「檢查更新」。
**還在用 0.1.0 的人**：0.1.0 不會提醒更新，請從這頁下載新版，直接安裝在舊版上面就好，不用先解除安裝，也不用重新配對。

**怎麼暫停或停止上傳？**
- GF Sync：在盾牌圖示上按右鍵，勾選「暫停同步」，或解除安裝 GF Sync。這只會停止這台電腦上傳。
- 綠皮冒險工具箱在遊戲內沒有開關，裝了就代表同意分享；不想分享的話，請不要安裝工具箱。
- 不想讓這台電腦同步了：到「[同步裝置](https://greenandfangadventure.com/pages/sync-devices)」頁面撤銷。

**怎麼移除？**
在盾牌圖示上按右鍵選「解除安裝 GF Sync…」，或到 Windows「設定 → 應用程式」移除。這台電腦的配對資料會一起刪除，遊戲資料夾不受影響。

**防毒軟體擋住了？**
GF Sync 是公會自己寫的開源程式（[原始碼](https://github.com/GreenAndFangAdventure/gf-sync)），因為還沒有數位簽章，少數防毒軟體可能誤判。可以核對檔案的 SHA-256 是否和下面一致，再把檔案加回來：

```
<SHA-256>  GFSync-Setup-<版本>.exe
```

（核對方式：在 PowerShell 執行 `Get-FileHash .\GFSync-Setup-<版本>.exe`）

如果 GF Sync 的選單顯示「沒有權限讀取」或「無法開啟自己的…」，代表防毒軟體擋住了 GF Sync 讀取檔案，不是找不到遊戲。處理方式見 [如果被防毒擋下](https://github.com/GreenAndFangAdventure/gf-sync#如果被防毒擋下)。

## 給 GearBot 的備註

- **防毒說明的連結**：GF Sync 選單 ⚠ 那一行在「被擋下」時會開啟 `https://github.com/GreenAndFangAdventure/gf-sync#如果被防毒擋下`（README 的標題「如果被防毒擋下」）。下載頁如果有自己的防毒說明，可以連到同一處或內容保持一致；README 的這個標題不要改名。

- 第 3 步 GF Sync 的小視窗標題是「已經幫你開啟瀏覽器」，內容有配對碼 XXXX-XXXX、「允許這台電腦同步」的說明，以及「重新開啟配對頁」和「複製配對碼」按鈕（按下複製後，視窗底部會顯示「已複製配對碼 …」）；配對完成、過期或被拒絕時會自己關掉。配對成功後的通知是「GF Sync 已連結：之後下線就會自動同步，不用再做任何事。」配對頁上的按鈕文字如果改了，請告訴 GF Sync 這邊一起改。
- 安裝畫面依序是：隱私權政策 → 附加工作：「開機時自動啟動 GF Sync（建議）」（預設勾選）和「在桌面建立捷徑」（預設不勾選）→ 安裝 → 完成（「現在啟動 GF Sync」預設勾選；完成頁會提醒圖示在右下角工作列、可能收在「^」裡）。玩家只需要按「下一步」和「完成」。
- **配對碼的複製與貼上（請 GearBot 確認網站端）**：GF Sync 的「複製配對碼」（小視窗上的按鈕和工作列選單）只會把配對碼本身放進剪貼簿，也就是網站發的 userCode 原樣，例如 `ABCDEFGH`：沒有連字號、空格或其他文字，也不會放 deviceCode 或 token。GF Sync 畫面上顯示的是 `ABCD-EFGH`，玩家可能照著打。如果配對頁有手動輸入配對碼的欄位，請讓它能接受下面這些輸入：
  - 前後或中間有空白、換行、Tab
  - 有連字號 `-`（包括全形 `－`、`ー` 等）
  - 小寫字母
  - 全形英數字（中文輸入法常見）。建議先做 NFKC 正規化，再轉大寫，最後只留下 A–Z、0–9，然後比對。

  網站端怎麼做由 GearBot 決定，GF Sync 這邊沒有改網站。如果配對頁只靠網址的 `?code=` 帶入、沒有輸入欄位，這一點就不需要處理。
